# 面试八股陪练 Skill

用于 Java 后端与 Agent 的逐题学习、模拟面试、证据评分和复习。

仓库仅提供 skill、流程协议与本地进度脚本。题目在使用时按学习范围生成，或由用户从本地提供。题库、参考答案、简历、真实回答和历史成绩均由使用者自行保管。

## 使用

将 skills/interview-bagu 整个目录安装到个人 Codex skills 目录下，目录名为 interview-bagu。运行脚本需要 Python 3.10 或以上，无需第三方 Python 包，也无需单独配置 API 密钥。

在对话中调用。

~~~text
使用 $interview-bagu，Java 和 Agent 交替问我，一次一道，答完评分。
~~~

也可以要求只练某个主题、先讲再测、复习薄弱项，或继续上次进度。首次使用由 skill 准备本地题目，后续恢复同一学习工作目录下的记录。

## 默认规则

| 项目 | 规则 |
| --- | --- |
| 计分 | 每题独立，满分 10 分 |
| 通过 | 8 分及以上 |
| 掌握 | 同题连续 5 次独立通过 |
| 复习 | 最近一次评分或跳过的 3 天后 |
| 未通过 | 连续次数清零，取消掌握，保留历史最佳 |
| 提示后通过 | 保留已有连续次数，本次不累加 |
| 跳过或未回答 | 分数为空，跳过不改变连续次数 |
| 持久化 | 本地 JSON、revision 检查、幂等答题 ID、写锁与原子替换 |

模型负责根据回答判断内容并解释评分，脚本负责校验和记录。可在新建学习记录时调整通过分数、连续次数和复习间隔。技术结论依据所讨论的版本，存在争议时应核对官方文档或源码。

## 本地数据

进度默认保存在学习工作目录的 .interview-bagu/，与 skill 安装目录分开。skill 会在首次写入前检查该目录是否被 Git 忽略。请勿将本地题目、payload 或进度文件提交到公开仓库。

脚本自身不发起网络请求。会话中的问题和回答仍由使用者所选对话平台处理。

文件格式、恢复规则和 CLI 命令见 [本地协议](skills/interview-bagu/references/protocol.md)。入口说明见 [SKILL.md](skills/interview-bagu/SKILL.md)。
